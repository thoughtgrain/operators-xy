# Screens

Design work for these machines' screens, written here by the operator-design MCP server (`.mcp.json` sets its
workspace to this repository). Each machine gets `screens/<machine-id>/`: the brief, the design passes, frames,
contact sheets and the `handoff.md` that `display.cpp` is implemented from.

The current toro (blocks) and theseus (tower) screens were designed before this repository existed; their design
files are in operator-design's own `screens/toro/` and `screens/theseus/`, and the theseus tower is in its library.
